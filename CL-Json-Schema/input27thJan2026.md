Regarding the reuse of the same content across different resources, where we agreed to replicate the content in the interim as there is an existing spreadsheet containing relationships that can we use to add / modify the structure:
The use of explicit parent relationships i.e. Lesson has a parent relationship to Topic, was used to help with querying and validation of the generated schemas, ie all questions are correctly linked to activities. Since the content is going to be ingested it is critical to ensure we can validate and adjust the structure if needed - without the need for reingestion. This does limit the ability to reuse the content ie an activity to be used within 2 lessons, however with the composable nature of the architecture, combined with the referencing, this linking can be achieved in several ways in the future without the need for reinvention.
In addition to this there is a singular reference for standards (ie standards linked to lesson - which is called a standards_block - see documentation), meaning only set of standards can be linked to lesson. Since we are moving forward with replicating the content this will work as expected, however if a lesson needs to be linked to multiple standards (is CA and TEX, not just CA) it will need to be amended. Once again not a big lift given our use of references within the individual content items.
In addition to this, I want to clarify something in the documentation which indicates that the use of resources (ie SPB, SRB) will allow content to be reused across states, while this is true it is only valid when the content is referencing the same standards - from memory this is a rare occurrence, mainly for when a resource might use the national standards but potentially have an addition or slight change depending on the state (Kevin correct me if I am wrong here)
